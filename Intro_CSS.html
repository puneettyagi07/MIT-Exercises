CSS stands for Cascading Style sheets

Css describes how HTML elements are displayed on the screen

There are three ways to use CSS:

  1. Inline CSS
  2. Internal CSS
  3. External CSS

Inline CSS is used to apply a unique style to a single element. To use inline styles, add the style attribute to the relevant element. The style attribute can contain any CSS property. Ex:-

we can use ID's and classes to target specific elements and apply styles to them. Id is the unique identifier for an element, while classes can be shared by multiple elements. Id takes more priority than classes. ID's are denoted by a hash symbol (#) followed by the ID name, and classes are denoted by a period (.) followed by the class name.


There are many CSS properties available for styling elements. Some common ones include color, background-color, font-size, font-family, margin, padding, and border, position.


CSS also allows for responsive design, which means that the layout and styling of a webpage can adapt to different screen sizes and devices. This is typically achieved using media queries, which apply different styles based on the characteristics of the device or screen size.


Overall, CSS is a powerful tool for controlling the visual presentation of web content and creating engaging and user-friendly websites.


Flexbox

Flexbox is a layout model in CSS that allows for the easy arrangement of elements in a container. It provides a more efficient way to distribute space and align items within a container, especially when the size of the items is unknown or dynamic.

With Flexbox, you can easily create flexible and responsive layouts without the need for complex CSS rules or JavaScript. It allows you to control the alignment, direction, and order of elements within a container, making it easier to create complex layouts with less code.

To use Flexbox, you need to set the display property of the container to flex. This will enable Flexbox for that container and allow you to use its properties to control the layout of the child elements. Some common Flexbox properties include justify-content, align-items, flex-direction, and flex-wrap.

Overall, Flexbox is a powerful tool for creating flexible and responsive layouts in CSS, and it is widely supported by modern browsers.

In CSS, it stands for Element Value / Element EM (Relative to its parent element's font size). 3. How to Set the HTML Base Font Size :- Always set base font sizes using percentages (%) rather than fixed px. This preserves accessibility settings for users who adjust their browser's default text size. Method A: The Modern Standard (100% Base)This keeps the default 16px base while respecting user browser preferences. Example for CSS file:- html { font-size: 100%; /* 100% of browser default (usually 16px) */ } Method B: The "62.5% Trick" (Simplifies Math) By setting html to 62.5%, you scale the base font size from 16px down to 10px (16 * 0.625 = 10). This makes mental math significantly easier: Example for CSS file :- html { font-size: 62.5%; /* Base becomes 10px */ } /* Now 1rem = 10px */ body { font-size: 1.6rem; /* 16px */ } p { font-size: 1.4rem; /* 14px */ } Warning on Hardcoding px on html: Avoid doing html { font-size: 16px; }. This hardcodes the font size and overrides the user's custom browser accessibility preferences if they have vision impairments. 4. Which Unit Should You Use? (The Complete Cheat Sheet) => Unit.
