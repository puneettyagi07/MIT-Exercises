What is HTML?

HTML stand for Hyper Text Markup Language. Although it's not a language.

HTML describes the structure of web page. It means it's used to build the structure of Web Page.



HTML Elements

An Element describes a component of our webpage. It's the combination of Opening Tag + Content + Closing Tag. Ex:-

this is HTML Element

They help us determine the structure of a page



General HTML Structure

It includes Doctype(Document type) + HTML tag in which HTML is the biggest tag + Head tag + Body tag. We can get by pressing escaliration mark + tab

Head includes only links and meta data

Body includes only content which has to be shown on webpage which is also divided into 3 parts navigation bar + Main + Footer

Image Tag

Image is a self closing tag. it includes the image link or directly image. It has default attribute of alt which is the alternate text of image in case image link is crashed or image does not get loaded


Anchor Tag

Anchor tag is used to link any page via making a link. we can convert any image, paragrapgh, word etc into a link. it has a default attribute of alt which says the links name. Also we can add one more attribute to open link into a new page which is target = _blank
